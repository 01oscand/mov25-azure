# Vecka 36 – Nätverk och säkerhet

Under vecka 36 bygger jag ett säkert nätverkslager för Novatrix AB.

Arbetet omfattar:
- Virtual Network (VNet)
- Subnät för webb och framtida lagring
- Network Security Group (NSG)
- HTTP och HTTPS
- Begränsad SSH
- Verifiering av tillåten och blockerad trafik
- Defense in depth
