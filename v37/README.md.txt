# Vecka 37 – Storage

Under V37 kopplas Azure Storage till Novatrix kundtjänstlösning.

Arbetet omfattar:

- Storage Account
- Azure Blob Storage
- Container för ärenden och bilagor
- Managed Identity
- RBAC
- Least privilege
- Säkrad nätverksåtkomst
- Ett fungerande ärendeformulär
- Verifiering av lagrade ärenden
